# kazkar-content

Статичний каталог книжок застосунку **Казкар** (GitHub Pages).

- `catalog.json` — індекс: `books[].{id,title,baseUrl,cover,free,version}`.
- `books/<id>/` — `manifest.json` (uk, фолбек) [+ `manifest.en.json`] + `cover` + `pNN.jpg`.
- `version` книжки — **бампати при кожній правці контенту** (тексти/зображення/переклади):
  застосунок порівнює її із закешованою копією і за новішої авто-оновлює книжку у фоні.
  Порівняння **монотонне (лише вгору)**: відкат контенту (git revert) публікувати теж
  бампом версії ВГОРУ — зниження version клієнти ігнорують. Значення — ціле число ≥ 1
  (не рядок!); невалідне клієнт толерантно трактує як 1 («оновлення немає»). Відсутнє
  поле = 1. `version` каталогу — версія схеми (клієнт ігнорує).
- Схема — дзеркало bundled-книжок застосунку; деталі в README основного репо.
